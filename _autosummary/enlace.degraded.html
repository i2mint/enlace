enlace.degraded¶

Loud-and-local app-load failures: a 500 stub for the one app that broke.

An asgi-mode app is mounted by importing it, in the gateway’s own process. Before this module, one app whose import raised took every worker down with it, and every app on the platform answered 502. Now load_or_stub() contains that failure to the app: the app’s route prefix answers 500 naming the app and the exception class, and the other apps serve.

A stub is not a degraded success. It is as loud as the crash-loop it replaces, only not as wide. Every stub is reported in four places, all fed by the same AppConfig.import_error record:

  • the logs: one ERROR line with the traceback per stubbed app, at boot;

  • /_meta: the platform payload gains degraded_apps, and the app’s own /_meta gains degraded (see degraded_apps());

  • /_apps: the app is listed with degraded: true and is not launchable;

  • enlace doctor: a FAIL check per stubbed app, read from the live gateway’s /_meta, so a failure only the server’s own identity hits (a file only it cannot read) is still reported.

What is contained is narrow on purpose: an asgi-mode app’s import, or the detection and loading of its sub-app. Platform configuration errors (a bad platform.toml, an unknown landing_app, route conflicts, a plugin that refuses its configuration) still refuse to boot, as do lifespan failures, an app with fail_hard = true in its app.toml, and every app when the platform sets app_load_failure = "raise". The decision and its reasons are recorded in misc/docs/decisions/0001-loud-and-local-app-load-failures.md.

class enlace.degraded.UnavailableApp(app_name, exception_type)[source]¶

Bases: object

Pure-ASGI stub standing in for an app that failed to load.

Every HTTP request answers 500 with a short plain-text body naming the app and the exception class — never the message or a traceback, which can carry server paths and is logged instead. A websocket handshake is refused (a close before accept: uvicorn answers it as an HTTP 403; the ASGI close code is 1011). It has no router, so the gateway’s lifespan cascade passes it by.

enlace.degraded.load_or_stub(strategy, app, platform)[source]¶

Return app’s ASGI sub-app, or a stub when an asgi app cannot load.

An app that discovery already recorded as un-importable is not imported a second time. A contained compose-time failure is recorded on app (mutated in place, like updated_at) so every reporting surface reads the same record. A failure that must not be contained is re-raised with its original traceback.

Return type:

Optional[Any]

enlace.degraded.refuse_to_boot_if_required(platform)[source]¶

Raise the first recorded load failure the configuration says not to stub.

For callers that act on a discovered config before build_backend runs — enlace serve spawns process-mode children and a supervised gateway — so fail_hard and app_load_failure = "raise" still stop everything up front, as they did when discovery raised.

Return type:

None
