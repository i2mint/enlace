enlace.response_headers¶

Per-app response headers declared in app.toml; cross-origin isolation in a line.

An app names headers for sub-paths of itself, and enlace adds them to every response on those paths, whoever produced it (the app’s frontend, its API, the sign-in gate):

cross_origin_isolated = ["lab"]   # COOP + COEP + CORP on /{name}/lab/...

[response_headers]
"lab" = { "Cross-Origin-Embedder-Policy" = "credentialless" }  # overrides one
"/" = { "X-Robots-Tag" = "noindex" }                           # the whole app

Both are off by default: an app that declares neither gets no header from here, and the middleware is not even installed when no app declares one.

Paths. A key is a sub-path of the app, "/" (or "") for all of it. It applies under each of the app’s mounts: the page at /{name}/ and the API at its route_prefix (so CORP: same-origin also lands on {route_prefix}/lab/, harmless for same-origin fetches). Matching is by whole segments: "lab" covers /{name}/lab and /{name}/lab/..., never /{name}/labels. A request belongs to the app with the longest mount covering it, and only that app’s keys apply, so one app’s declaration never reaches another app’s paths. When several of its keys match, the longest wins header by header. A declared header replaces one of the same name already on the response. Headers that would corrupt the response or act on the whole origin (Set-Cookie, framing headers, Clear-Site-Data, Strict-Transport-Security…) are refused: see FORBIDDEN_HEADERS. So is Access-Control-*, the platform’s CORS answer: see FORBIDDEN_HEADER_PREFIXES.

Cross-origin isolation. cross_origin_isolated = true (the whole app) or a list of sub-paths sends CROSS_ORIGIN_ISOLATION_HEADERS. A page served with them gets crossOriginIsolated === true, hence SharedArrayBuffer (threaded WebAssembly, memory shared with an AudioWorklet) and precise timers. The price, on every isolated page: a cross-origin resource loads only if it opts in (CORS, or Cross-Origin-Resource-Policy: cross-origin), so third-party embeds (YouTube and other iframes, analytics and ad scripts, images and fonts from a CDN that sends no CORP) stop loading; a window it opens, or that opened it, loses its handle to it unless same-origin (OAuth and payment pop-ups that report back through window.opener); and CORP: same-origin stops other sites embedding its files. Keep it on the one route that needs it, and mind three consequences:

  • Workers. A dedicated worker started by an isolated page must have its script served with a compatible COEP, or it does not start at all. Put worker scripts (and the scripts that spawn threads, such as onnxruntime-web’s .mjs) under the isolated sub-path. Same-origin page scripts, wasm and data elsewhere need nothing.

  • Navigation. Isolation is fixed when a document loads: a client-side route change into the isolated path does not isolate the page; link to it with a full navigation.

  • SPA fallback. An unknown path under the isolated sub-path falls back to the app’s root index.html, served isolated; give the isolated page its own index.html and link to that.

The three-callable middleware is pure ASGI, as every enlace middleware is.

Header-name prefixes an app may not declare (lower-case). access-control-* is the platform’s CORS answer: this middleware wraps CORS, so a declared value would replace it, e.g. pairing a chosen origin with Allow-Credentials on the app’s API.

class enlace.response_headers.ResponseHeadersMiddleware(app, *, rules, mounts=())[source]¶

Bases: object

Pure-ASGI middleware adding declared headers to responses under path prefixes.

rules are (mount, prefix, headers) triples on full request paths. A request is owned by the longest of mounts covering it (every app’s mounts, so an app with a shorter mount never reaches a longer one’s paths); only the rules of that mount apply, longer prefixes last, so the most specific wins a header both declare. Websockets and lifespan pass through untouched.

>>> import asyncio
>>> async def app(scope, receive, send):
...     await send({"type": "http.response.start", "status": 200, "headers": []})
...     await send({"type": "http.response.body", "body": b""})
>>> mw = ResponseHeadersMiddleware(app, rules=[("/a", "/a", {"X-A": "1"})])
>>> sent = []
>>> async def send(m): sent.append(m)
>>> asyncio.run(mw({"type": "http", "path": "/a/b"}, None, send))
>>> sent[0]["headers"]
[(b'x-a', b'1')]
